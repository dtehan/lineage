  4. Create `lineage-api/graph/store.py`:
     - Import `time`, `psutil`, `os`, `dataclasses.dataclass`, `dataclasses.field`, `networkx`.
     - Define `@dataclass` class `GraphStore` with fields:
       - `graph: nx.DiGraph`
       - `node_count: int`
       - `edge_count: int`
       - `loaded_at: float = field(default_factory=time.time)`
       - `memory_bytes: int = 0`
     - Add `@classmethod` `build(cls, graph: nx.DiGraph) -> "GraphStore"`:
       - Measure `psutil.Process(os.getpid()).memory_info().rss` for memory_bytes.
       - Return `cls(graph=graph, node_count=graph.number_of_nodes(), edge_count=graph.number_of_edges(), loaded_at=time.time(), memory_bytes=rss)`.
     - Add module docstring explaining this is an immutable snapshot for blue-green swap.

  5. Create `lineage-api/graph/loader.py`:
     - Import `networkx as nx`, `loguru.logger`.
     - Define `class GraphLoader`:
       - `__init__(self, connection)`: stores the Teradata connection.
       - `load(self) -> nx.DiGraph`:
         - Creates a new `nx.DiGraph()`.
         - Opens a cursor: `with self.connection.cursor() as cur:`.
         - Executes the query (using LOCKING ROW FOR ACCESS to avoid locks):
           ```sql
           LOCKING ROW FOR ACCESS
           SELECT
               source_dataset,
               source_field,
               target_dataset,
               target_field,
               transformation_type
           FROM OL_COLUMN_LINEAGE
           WHERE is_active = 'Y'
           ```
         - Iterates `cur.fetchall()`. For each row:
           - Strip whitespace from all string fields (Teradata CHAR padding): `row[N].strip() if row[N] else ""`.
           - Build source node ID: `f"{source_dataset}.{source_field}"` — this matches `LineageService._build_node()` key format.
           - Build target node ID: `f"{target_dataset}.{target_field}"`.
           - Get transformation_type: `(row[4] or "DIRECT").strip()`.
           - `G.add_edge(src_id, tgt_id, transformation_type=ttype)`.
         - Log the loaded count: `logger.info("GraphLoader: loaded graph", nodes=G.number_of_nodes(), edges=G.number_of_edges())`.
         - Return `G`.

  IMPORTANT: The node ID format MUST be `"dataset_name.field_name"` where dataset_name is already fully qualified (e.g., `"demo_user.customer"`). This means the full node ID is like `"demo_user.customer.customer_id"`. The `rsplit(".", 1)` in the engine (Plan 14-02) will correctly split this into `("demo_user.customer", "customer_id")`.
