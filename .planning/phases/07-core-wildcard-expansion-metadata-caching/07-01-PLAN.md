**Class design:**

```python
class WildcardResolver:
    """Resolves SELECT * wildcards by batch-querying Teradata column metadata.

    Designed for single-extraction-run lifetime: warm cache once with all
    referenced tables, then resolve wildcards from cache. No TTL needed.
    """

    def __init__(self, cursor, default_database: str):
        self.cursor = cursor
        self.default_database = default_database
        self._column_cache: Dict[Tuple[str, str], List[str]] = {}
        self._cache_misses: int = 0
        self._cache_hits: int = 0

    def warm_cache(self, table_refs: Set[Tuple[str, str]]) -> None:
        """Batch-query metadata for all referenced tables in a single round-trip."""

    def resolve_star(self, database: Optional[str], table: str) -> List[str]:
        """Return column names in ordinal position order from cache."""

    def normalize_identifier(self, identifier: str, is_quoted: bool = False) -> str:
        """Normalize identifier for Teradata case-insensitive matching."""

    def get_stats(self) -> Dict[str, int]:
        """Return cache hit/miss statistics for logging."""
```

**Implementation details for `warm_cache()`:**
1. Accept `Set[Tuple[str, str]]` of (database, table) references
2. Skip if `table_refs` is empty (no-op)
3. Normalize all identifiers: unquoted -> uppercase, quoted -> preserve case (CORE-06)
4. Use default_database when database is None or empty
5. Deduplicate table references after normalization
6. Build batch query using OR conditions (up to 100 per batch, paginate if more):
   ```sql
   SELECT TRIM(DatabaseName), TRIM(TableName), TRIM(ColumnName), ColumnId
   FROM DBC.ColumnsJQV
   WHERE (DatabaseName = 'DB1' AND TableName = 'TBL1')
      OR (DatabaseName = 'DB1' AND TableName = 'TBL2')
      ...
   ORDER BY DatabaseName, TableName, ColumnId
   ```
7. Group results by (database, table) and store as `List[str]` of column names ordered by ColumnId
8. Log summary: "Warmed metadata cache: {N} tables, {M} columns in {T}ms"
9. Wrap entire operation in try/except: log warning on failure, don't raise (CORE-04 graceful degradation)

**Implementation details for `resolve_star()`:**
1. Normalize database (default if None) and table to uppercase
2. Look up `(database, table)` in `_column_cache`
3. Track hit/miss statistics
4. Return cached `List[str]` if found, empty list `[]` if not found
5. Never raise exceptions

**Implementation details for `normalize_identifier()`:**
1. If `is_quoted=True`, return as-is (preserve exact case for quoted identifiers like `"MyTable"`)
2. If `is_quoted=False`, return `.upper()` (Teradata stores unquoted identifiers uppercase)
3. Strip surrounding whitespace
