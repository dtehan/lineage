<objective>
Add Redis-backed graph persistence so cold application restarts restore the in-memory DiGraph from Redis within <1 second instead of re-querying Teradata. Implement save-on-warmup, restore-on-startup, invalidate-on-ETL, and verify memory stability across rebuild cycles.

Purpose: Eliminate the slow Teradata-based graph warm-up on routine application restarts when the lineage data has not changed, reducing time-to-ready from seconds to milliseconds.
Output: `graph/serializer.py` module, updated `engine.py` with Redis-aware warmup, updated `python_server.py` with redis_client wiring, comprehensive unit tests.
</objective>

**1. Create `lineage-api/graph/serializer.py`** with three module-level functions:

- `GRAPH_KEY = "lineage:engine:snapshot"` constant. This key is intentionally outside the `lineage:graph:*` namespace to avoid accidental deletion by `invalidate_all()` in `cache/invalidation.py`.

- `save(G: nx.DiGraph, redis_client) -> None`:
  - Call `nx.node_link_data(G)` to get a JSON-serializable dict.
  - `json.dumps(data).encode("utf-8")` to get bytes.
  - `redis_client.set(GRAPH_KEY, json_bytes)` with NO TTL (explicit invalidation only).
  - Log with loguru: node count, edge count, byte size.
  - Wrap entire body in try/except; log warning on failure (non-fatal).

- `restore(redis_client) -> nx.DiGraph | None`:
  - `redis_client.get(GRAPH_KEY)` — return None if key missing.
  - `json.loads(raw)` — catch JSONDecodeError, return None.
  - `nx.node_link_graph(data)` — this respects `data['directed']`.
  - `isinstance(G, nx.DiGraph)` check — if False, log warning and return None (corrupt `directed` field protection).
  - Log success with node/edge counts.
  - Catch all exceptions, return None on failure.

- `invalidate(redis_client) -> None`:
  - `redis_client.delete(GRAPH_KEY)`.
  - Log info on success, warning on failure.
  - Wrap in try/except (non-fatal).

Include module docstring explaining key choice, format (UTF-8 JSON from `node_link_data`), and TTL policy (none — explicit invalidation).

**2. Update `lineage-api/graph/engine.py`**:

- `initialize(self, connection, redis_client=None) -> None`:
  - Add `redis_client=None` parameter.
  - Store as `self._redis = redis_client` BEFORE creating the loader.
  - Rest of method unchanged (create loader, start thread).

- `_warmup(self) -> None` — rewrite to try Redis restore first:
  ```
  try:
      # Fast path: try Redis restore
      if self._redis is not None:
          from graph.serializer import restore as redis_restore, save as redis_save
          graph = redis_restore(self._redis)
          if graph is not None:
              self._swap(graph)
              self._ready.set()
              logger.info("Graph engine: restored from Redis", ...)
              return

      # Slow path: Teradata load
      graph = self._loader.load()
      self._swap(graph)

      # Persist to Redis for future restarts
      if self._redis is not None:
          from graph.serializer import save as redis_save
          redis_save(graph, self._redis)

      self._ready.set()
      logger.info("Graph engine: warmup complete (Teradata load)", ...)
  except Exception as exc:
      logger.error("Graph engine: warmup failed, staying in CTE fallback mode", ...)
  ```
  Note: Use lazy imports (inside the method, conditional on `self._redis is not None`) to avoid circular import risk and keep the module importable without Redis. This matches the existing codebase style in `routes/cache.py`.

- `invalidate(self) -> bool` — add Redis snapshot deletion BEFORE clearing ready:
  ```
  if self._loader is None:
      ...return False

  # Delete Redis snapshot so _warmup() does a fresh Teradata load
  if self._redis is not None:
      from graph.serializer import invalidate as redis_invalidate
      redis_invalidate(self._redis)

  # Existing steps unchanged:
  self._ready.clear()
  with self._lock:
      self._store = None
  thread = ...
  ```
  The snapshot must be deleted BEFORE `_ready.clear()` so that if the rebuild thread starts immediately, it will not find a stale snapshot.

- Add `self._redis = None` to `__init__`.

Do NOT change the module-level singleton pattern or any other methods (traverse_upstream, traverse_downstream, status, _swap, _bfs_edges).
