   ```typescript
   /** Duration in ms for each completed stage (populated when stage exits) */

   ```

2. Add state and ref inside the hook:
   ```typescript
   const stageStartTimeRef = useRef<number | null>(null);
   const [stageDurations, setStageDurations] = useState<Partial<Record<LoadingStage, number>>>({});
   ```

3. Modify the `setStage` callback to record durations when transitioning between stages. Inside the `setStageState` updater function (which receives the guaranteed-correct `prevStage`):
   - When the previous stage is NOT 'idle' and `stageStartTimeRef.current` is not null, compute `elapsed = performance.now() - stageStartTimeRef.current` and call `setStageDurations(prev => ({ ...prev, [prevStage]: Math.round(elapsed) }))`. Use `Math.round()` for clean integer ms display.
   - Set `stageStartTimeRef.current` for the new stage: if newStage is NOT 'idle' and NOT 'complete', set to `performance.now()`. Otherwise set to `null`.
   - When transitioning FROM idle to a non-idle stage (loading start), also set `stageStartTimeRef.current = performance.now()` for the new stage.

4. Modify the `reset` callback to clear `stageDurations` and `stageStartTimeRef`:
   ```typescript
   setStageDurations({});
   stageStartTimeRef.current = null;
   ```

5. Return `stageDurations` from the hook.

6. Add a `formatMs` helper function (exported) that formats milliseconds for display:
   - If < 1000: return `${ms}ms` (e.g., "85ms")
   - If >= 1000: return `${(ms / 1000).toFixed(1)}s` (e.g., "1.2s")

   - `test stageDurations accumulates across all stages`: Transition through fetching -> layout -> rendering -> complete, assert all three durations are recorded.
   - `test reset clears stageDurations`: Populate durations, call reset, assert `stageDurations` is `{}`.
   - `test formatMs formats milliseconds correctly`: Test `formatMs(85)` returns "85ms", `formatMs(1200)` returns "1.2s", `formatMs(500)` returns "500ms".

IMPORTANT: Use `performance.now()` (NOT `Date.now()`) for stage timing — it is monotonic and sub-millisecond. Mock `performance.now` in tests using `vi.spyOn(performance, 'now')`.
