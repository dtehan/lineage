  <name>Task 1: Add impact analysis route to Blueprint</name>
  <files>lineage-api/routes/openlineage.py</files>
  <action>
Add a new route to the openlineage_bp Blueprint in lineage-api/routes/openlineage.py:

GET /impact/<path:dataset_id>/<field_name>

Route handler:
1. Parse query parameter: maxDepth (default 5, type int)
2. Call impact_service.analyze_downstream_impact(dataset_id, field_name, max_depth)
3. Return jsonify(result), 200
4. On ValueError (dataset not found): return jsonify({"error": str(e)}), 404
5. On Exception: return jsonify({"error": str(e)}), 500

The full URL will be /api/v2/openlineage/impact/{datasetId}/{fieldName} due to the Blueprint prefix.

Expected response shape (from ImpactService):
```json
{
  "sourceAsset": {
    "datasetId": "...",
    "datasetName": "...",
    "fieldName": "..."
  },
  "impactedAssets": [
    {
      "databaseName": "demo_user",
      "tableName": "STG_SALES",
      "columnName": "sale_amount",
      "depth": 1,
      "impactType": "direct"
    }
  ],
  "summary": {
    "totalImpacted": 5,
    "tableCount": 3,
    "columnCount": 5,
    "databaseCount": 1,
    "byDatabase": {"demo_user": 5},
    "byDepth": {"1": 2, "2": 3}
  }
}
```

Also add a query parameter validation: if maxDepth > 10, clamp to 10 (per research recommendation on max recommended depth). If maxDepth < 1, clamp to 1.
