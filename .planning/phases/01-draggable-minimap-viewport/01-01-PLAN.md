    **Step 1: Create `LineageMiniMap.tsx`**

    Create a new shared component at `lineage-ui/src/components/domain/LineageGraph/LineageMiniMap.tsx` that wraps `<MiniMap />` from `@xyflow/react` with consistent interactive props:

    ```tsx
    import { MiniMap } from '@xyflow/react';
    import type { Node } from '@xyflow/react';

    interface LineageMiniMapProps {
      nodeColor?: (node: Node) => string;
    }

    export function LineageMiniMap({ nodeColor = () => '#94a3b8' }: LineageMiniMapProps) {
      return (
        <MiniMap
          pannable={true}
          zoomable={true}
          nodeColor={nodeColor}
          maskColor="rgba(0, 0, 0, 0.08)"
          maskStrokeColor="#3b82f6"
          maskStrokeWidth={1}
          style={{ bottom: 56 }}
          className="lineage-minimap--interactive"
        />
      );
    }
    ```

    Key design decisions:
    - `nodeColor` is the only prop that differs between the three graph components. LineageGraph has a custom `nodeColor` function that highlights the focused field in blue; the other two use a flat `() => '#94a3b8'`. Accept `nodeColor` as an optional prop with the flat color as default.
    - `maskColor` slightly reduced to `0.08` opacity (from `0.1`) for better viewport visibility when interactive.
    - `maskStrokeColor="#3b82f6"` adds a blue border around the viewport indicator to signal draggability.
    - `maskStrokeWidth={1}` keeps the stroke subtle (value is multiplied by viewScale internally).
    - `className="lineage-minimap--interactive"` used as CSS hook for cursor styles.
    - `style={{ bottom: 56 }}` preserved from existing implementation (positions above toggle button).

    **Step 2: Add cursor CSS to `lineage-ui/src/index.css`**

    Add the following CSS rules after the existing `.no-transitions` block (before the `@media (prefers-reduced-motion)` block):

    ```css
    /* Interactive minimap cursor feedback */
    .lineage-minimap--interactive .react-flow__minimap-svg {
      cursor: grab;
    }
    .lineage-minimap--interactive .react-flow__minimap-svg:active {
      cursor: grabbing;
    }
    ```

    This provides visual feedback that the minimap is draggable. React Flow does NOT add cursor styles automatically when `pannable={true}`.
