Three changes are needed. All follow the pattern already established by `get_database_lineage_graph()` in the same file.

**Change 1: dataset_repository.py — Extend get_dataset_with_namespace()**

Add `d.source_type` to the SELECT query and include `"source_type"` in the returned dict. This provides the root dataset's type to column/table lineage callers.

Current SQL: `SELECT d."name", n.namespace_uri`
New SQL: `SELECT d."name", n.namespace_uri, d.source_type`

Current return: `{"name": ..., "namespace_uri": ...}`
New return: `{"name": ..., "namespace_uri": ..., "source_type": self._strip(row[2]) if row[2] else "TABLE"}`

This is backward-compatible — callers that don't read `source_type` are unaffected.

**Change 2: lineage_service.py — Extend _build_node()**

Add an optional `source_type` parameter (default `"TABLE"`) and include `"sourceType": source_type` in the returned `dataset` dict.

```python
def _build_node(self, key: str, field_name: str, dataset_name: str, namespace: str, source_type: str = "TABLE") -> dict:
    return {
        "id": key,
        "type": "field",
        "name": field_name,
        "dataset": {
            "name": dataset_name,
            "namespace": namespace,
            "sourceType": source_type
        }
    }
```

The `"sourceType"` key name must be camelCase (not snake_case) because the frontend `openLineageAdapter.ts` reads `olNode.dataset.sourceType` — this is the established contract from `get_database_lineage_graph()`.

**Change 3: lineage_service.py — Add _get_source_type() helper and update _add_lineage_results()**

Add a new helper method `_get_source_type(self, dataset_name: str, cache: dict) -> str` that:
1. Checks `cache` dict for `dataset_name`
2. If not found, calls `self.dataset_repo.get_dataset_metadata(dataset_name)`
3. Returns `meta["sourceType"]` if found, else `"TABLE"` as default
4. Stores result in cache for reuse

```python
def _get_source_type(self, dataset_name: str, cache: dict) -> str:
    if dataset_name not in cache:
        meta = self.dataset_repo.get_dataset_metadata(dataset_name)
        cache[dataset_name] = meta["sourceType"] if meta else "TABLE"
    return cache[dataset_name]
```

Update `_add_lineage_results()` signature to accept `source_type_cache: dict = None`. Inside the method:
- If `source_type_cache is None`, create a new empty dict (for backward compatibility)
- For each source and target node, call `self._get_source_type(dataset_name, source_type_cache)` to get the sourceType
- Pass source_type to `self._build_node()` calls

**Change 4: lineage_service.py — Update get_column_lineage_graph() and get_table_lineage_graph()**

In both methods:
1. After `get_dataset_with_namespace()`, extract `source_type = dataset_info.get("source_type", "TABLE")`
2. Create `source_type_cache = {dataset_name: source_type}` (pre-seed with root dataset)
3. Pass `source_type_cache` to all `_add_lineage_results()` calls
4. Pass `source_type` to root `_build_node()` calls

For `get_column_lineage_graph()` — the root node at line 83 must also receive source_type.
For `get_table_lineage_graph()` — the root nodes at line 138 must also receive source_type.
