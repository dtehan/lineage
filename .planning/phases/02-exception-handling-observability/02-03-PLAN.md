  <name>Task 1: Strip try/except blocks from all route handlers</name>
  <files>
    lineage-api/routes/openlineage.py
  </files>
  <action>
Refactor every route handler in `routes/openlineage.py` to remove try/except blocks. The global error handlers (registered in Plan 02) now catch all exceptions, so route-level error handling is redundant.

**For each of the 12 route handlers:**

1. Remove `import traceback` from the file's imports.

2. For routes that had `try/except ValueError + except Exception` pattern (get_namespace, list_datasets, get_dataset, get_dataset_statistics, get_dataset_ddl, get_column_lineage, get_table_lineage, get_database_lineage, get_impact_analysis):
   - Remove the try/except wrapper entirely
   - Keep the service call and return statement at the same indentation level as the function body
   - The DatasetNotFoundError (replacing ValueError) is caught by the global handler returning 404
   - Other exceptions are caught by the catch-all global handler returning 500

3. For routes that had only `except Exception` pattern (list_namespaces, search_datasets, unified_search):
   - Remove the try/except wrapper entirely
   - Keep the service call and return statement

4. For search_datasets and unified_search: Keep the early return for short queries (`if not query or len(query) < 2: return jsonify({"error": ...}), 400`) -- this is input validation, not exception handling.

**Example transformation (get_dataset):**

BEFORE:
```python
@openlineage_bp.route("/datasets/<path:dataset_id>", methods=["GET"])
def get_dataset(dataset_id):
    """Get a specific dataset with its fields."""
    try:
        result = dataset_service.get_dataset(dataset_id)
        return jsonify(result)
    except ValueError as e:
        return jsonify({"error": str(e)}), 404
    except Exception as e:
        traceback.print_exc()
        return jsonify({"error": str(e)}), 500
```

AFTER:
```python
@openlineage_bp.route("/datasets/<path:dataset_id>", methods=["GET"])
def get_dataset(dataset_id):
    """Get a specific dataset with its fields."""
    result = dataset_service.get_dataset(dataset_id)
    return jsonify(result)
```

The route is now clean -- just service call and response. DatasetNotFoundError from service propagates to global handler (404). Any other exception propagates to catch-all handler (500 with sanitized message).
