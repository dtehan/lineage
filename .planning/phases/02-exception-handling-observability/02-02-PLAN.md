**middleware/__init__.py:**
- Empty package marker file.

**middleware/correlation_id.py:**
- Define `init_correlation_id_middleware(app)` function.
- `@app.before_request`: Generate UUID4 correlation ID OR extract from incoming `X-Correlation-ID` or `X-Request-ID` header. Store in `flask.g.correlation_id`. Call `logger.contextualize(correlation_id=correlation_id)` to bind it to all loguru messages for this request.
- `@app.after_request`: Add `X-Correlation-ID` header to every response from `g.correlation_id`.
- CRITICAL: Use `logger.contextualize()`, NOT `logger.bind()`. The `contextualize()` method uses `contextvars` for thread safety, preventing correlation ID leaking across concurrent requests.
- Also log the request method, path, and status code at INFO level in `after_request` for request-level observability.

**middleware/error_handlers.py:**
- Define `register_error_handlers(app)` function.
- Import domain exceptions from `exceptions` package and `sanitize_error_message` from `utils.sanitize`.
- Register handlers in this exact order (specific to general):
  1. `@app.errorhandler(DatasetNotFoundError)`: Log at WARNING level (not error -- 404s are expected). Return `jsonify(e.to_dict()), e.status_code`.
  2. `@app.errorhandler(LineageException)`: Log at ERROR level with `logger.exception()` for full traceback. Return `jsonify(e.to_dict()), e.status_code`.
  3. `@app.errorhandler(Exception)`: Catch-all. First check `isinstance(e, HTTPException)` from werkzeug and pass through unchanged. For other exceptions: sanitize the error message, log with `logger.exception()`, return `jsonify({"error": sanitized_message}), 500`.
- Get `correlation_id` from `g` in each handler (with `getattr(g, 'correlation_id', 'unknown')` fallback) for logging context. Note: correlation ID is already bound via `contextualize()` so it appears in logs automatically, but explicitly include it in the log message for clarity.

**python_server.py:**
- Add imports for `configure_logging`, `init_correlation_id_middleware`, `register_error_handlers`.
- In `create_app()`, add these calls in this order:
  1. `configure_logging()` -- FIRST, before anything else, so all subsequent startup logging uses structured format
  2. After CORS setup: `init_correlation_id_middleware(app)`
  3. After Blueprint registration: `register_error_handlers(app)` -- LAST, so error handlers are registered after all routes
- Replace the `print(f"Starting...")` in `__main__` with `logger.info(f"Starting...")`
- Import loguru: `from loguru import logger`

**lineage_service.py** has 3 ValueError raises to replace:

- `get_table_lineage_graph()`: Two raises -- "Dataset not found" and "No fields found for dataset" -> both `raise DatasetNotFoundError(...)`

**impact_service.py** has 1 ValueError raise to replace:
