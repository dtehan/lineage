Per RESEARCH.md Pattern 4 (Concurrent Access with Locking Hint): "Prevents write locks during read-only queries, allows concurrent access without lock contention."

**Update database/shared/cte_functions.py:**

Add LOCKING hint to both get_upstream_lineage_cte() and get_downstream_lineage_cte():

```python
def get_upstream_lineage_cte(database: str, target_dataset: str, target_field: str, max_depth: int = 10) -> str:
    """Build upstream CTE query with locking hint for concurrent access."""
    return f"""
        LOCKING ROW FOR ACCESS
        WITH RECURSIVE lineage_path (
            ...
        ) AS (
            ...
        )
        SELECT * FROM lineage_path
    """
```
