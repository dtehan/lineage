<objective>
Add connected component detection via BFS and extract the Kahn topological sort into a reusable helper, then refactor layoutGraph() to run Kahn + longest-path layering independently per connected component, stacking components vertically with shared x-axis columns.

Purpose: This is the algorithmic foundation for the two-zone layout. Without per-component layering, isolated tables land at layer 0 alongside genuine source tables, producing incorrect mixed layouts.

Output: Two new exported functions (detectConnectedComponents, kahnSort) and a refactored layoutGraph that processes connected components independently while preserving all existing behavior for single-component graphs.
</objective>

- Return `{ connected: Set<string>[], isolated: string[] }`

- While loop: shift, push to result, decrement neighbors' inDeg, binary-search splice on deg=0

     const subAdj = new Map<string, Set<string>>();
     const subInDeg = new Map<string, number>();
     for (const id of component) {
       subAdj.set(id, new Set());
       subInDeg.set(id, 0);

         if (component.has(tgt)) {
           subAdj.get(id)!.add(tgt);
           subInDeg.set(tgt, (subInDeg.get(tgt) ?? 0) + 1);
         }

     // Track max secondary position for this component to compute next componentYOffset
   }
