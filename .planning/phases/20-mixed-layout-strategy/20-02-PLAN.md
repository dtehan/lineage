**Step 1 — Add `placeIsolatedGrid` function to layoutEngine.ts:**

Add a new function (NOT exported — internal to layoutGraph) that places isolated tables in a compact alphabetical grid:

```typescript
/**
 * Places isolated tables in a compact alphabetical grid.
 * For horizontal directions (RIGHT/LEFT): grid flows left-to-right, wraps below.
 * For vertical directions (UP/DOWN): grid flows top-to-bottom, wraps right.
 */
function placeIsolatedGrid(
  isolated: string[],
  tableNodeData: TableNodeData[],
  startPrimary: number,     // where the grid zone begins on the secondary axis
  nodeSpacing: number,
  isHorizontal: boolean,
  maxRowWidth: number,
): Node[] {
  const nodes: Node[] = [];
  let currentPrimary = 0;   // primary axis position within grid (resets per row)
  let currentSecondary = startPrimary;
  let rowMaxPrimary = 0;    // tracks tallest/widest node in current row for wrapping

  for (const tableId of isolated) {
    const td = tableNodeData.find((t) => t.id === tableId)!;
    const width = calculateTableNodeWidth(td.tableName, td.columns);
    const height = calculateTableNodeHeight(td.columns.length, td.isExpanded);

    // For horizontal directions: grid rows flow along x (primary), wrap along y (secondary)
    // For vertical directions: grid rows flow along y (primary), wrap along x (secondary)
    const primarySize = isHorizontal ? width : height;
    const secondarySize = isHorizontal ? height : width;

    // Wrap to next row if this node exceeds maxRowWidth
    if (currentPrimary > 0 && currentPrimary + primarySize > maxRowWidth) {
      currentSecondary += rowMaxPrimary + nodeSpacing;
      currentPrimary = 0;
      rowMaxPrimary = 0;
    }

    nodes.push({
      id: tableId,
      type: 'tableNode',
      position: {
        x: isHorizontal ? currentPrimary : currentSecondary,
        y: isHorizontal ? currentSecondary : currentPrimary,
      },
      data: td,
    } as Node);

    rowMaxPrimary = Math.max(rowMaxPrimary, secondarySize);
    currentPrimary += primarySize + nodeSpacing;
  }

  return nodes;
}
```

**Step 2 — Integrate into layoutGraph():**

In `layoutGraph()`, after the per-component loop from Plan 20-01 (which sets `componentYOffset` to the bottom of all connected components), replace the temporary isolated positioning with `placeIsolatedGrid`:

1. Compute `maxConnectedExtent`: the maximum secondary-axis extent of all connected nodes. For RIGHT direction, this is `max(node.y + nodeHeight)` across all connected `layoutedNodes`. Use the `componentYOffset` value that was tracked during the per-component loop.

2. Compute `maxConnectedPrimaryExtent`: the maximum primary-axis extent of connected nodes. For RIGHT, this is `max(node.x + nodeWidth)`. This becomes the basis for `maxRowWidth`.

3. Set `gridGap = 80` (constant, same as `componentGap`).

4. Set `startY = componentYOffset + gridGap` (the secondary-axis start of the isolated grid zone). Note: `componentYOffset` after the loop already accounts for the last component's height + gap, but we want an additional grid gap.

5. Set `maxRowWidth = Math.max(1200, maxConnectedPrimaryExtent)` — dynamic width matching connected section.

6. Call `placeIsolatedGrid(isolated, tableNodeData, startY, nodeSpacing, isHorizontal, maxRowWidth)`.

7. Append the returned nodes to `layoutedNodes`.

8. The LEFT/UP reversal and `separateDatabaseClusters` call must operate on ALL nodes (connected + isolated). Verify these remain AFTER the isolated grid placement.
