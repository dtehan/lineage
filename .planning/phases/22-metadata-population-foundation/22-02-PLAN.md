**Part A: Add list_databases() method**

Add a new method `list_databases(self, namespace_id: str)` to the `DatasetRepository` class. Place it after the `list_namespaces` method and before `get_dataset`.

The method executes this SQL (Teradata-native STRTOK for database name extraction):

```sql
SELECT
    TRIM(STRTOK(d."name", '.', 1)) AS database_name,
    SUM(CASE WHEN d.source_type = 'TABLE' THEN 1 ELSE 0 END) AS table_count,
    SUM(CASE WHEN d.source_type = 'VIEW' THEN 1 ELSE 0 END) AS view_count,
    COUNT(*) AS total_count
FROM OL_DATASET d
WHERE d.namespace_id = ?
GROUP BY 1
ORDER BY 1
```

Return format: list of dicts, each with keys `name` (str), `tableCount` (int), `viewCount` (int), `totalCount` (int). Use `self._strip()` on the name. Default int values to 0 if None.

```python
def list_databases(self, namespace_id: str):
    """List distinct database names with table/view counts from OL_DATASET."""
    with self.connection.cursor() as cur:
        cur.execute("""
            SELECT
                TRIM(STRTOK(d."name", '.', 1)) AS database_name,
                SUM(CASE WHEN d.source_type = 'TABLE' THEN 1 ELSE 0 END) AS table_count,
                SUM(CASE WHEN d.source_type = 'VIEW' THEN 1 ELSE 0 END) AS view_count,
                COUNT(*) AS total_count
            FROM OL_DATASET d
            WHERE d.namespace_id = ?
            GROUP BY 1
            ORDER BY 1
        """, [namespace_id])
        rows = cur.fetchall()
        return [
            {
                "name": self._strip(row[0]) if row[0] else "",
                "tableCount": int(row[1]) if row[1] else 0,
                "viewCount": int(row[2]) if row[2] else 0,
                "totalCount": int(row[3]) if row[3] else 0,
            }
            for row in rows
        ]
```

The count query becomes:
```python
if database_filter:

        SELECT COUNT(*)
        FROM OL_DATASET

          AND "name" LIKE ?
    """, [namespace_id, f"{database_filter}.%"])

    cur.execute("""
        SELECT COUNT(*)
        FROM OL_DATASET
        WHERE namespace_id = ?
    """, [namespace_id])

The main data query: add `AND d."name" LIKE ?` before the closing `)` of the inner SELECT's WHERE clause, and add the pattern to params. When no filter, keep existing behavior unchanged.

Implementation approach: Build the WHERE clause conditionally. The cleanest way is to use an `extra_where` string and `extra_params` list:

```

Then inject `extra_where` into both the count and data SQL strings via f-string, and extend the params lists with `extra_params`.
